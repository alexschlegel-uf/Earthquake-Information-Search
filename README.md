<h2> How to Run </h2>

Running is simple. Intially it will print the amount of loaded earthquakes before then prompting to enter numbers 1-14, spaces in between each, for the different categories you wish to search under. It will then go one by one, asking for the value you wish to search for, and print whether or not it found that value. If it does, it returns the index. If it does not, it returns an index above and below where the value would be. So if you searched for 100 and couldn't find it, it would return the index of 99 and the index of 101.
