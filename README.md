<h2> How to Run </h2>

Running is simple. Will intially prompt to choose how to search. Values 1-3 correspond to Interpolation, Fibonacci, or both. Then, will prompt to choose variables to search by. After selecting all, will go through, asking for values to search for, and printing results. Will return index if found, otherwise will return nearby indexes and their values.
